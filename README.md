# Ocean Muck · 深蓝漂流

v0.7.1 碧海新境 · HUD 改进：第一人称低多边形海洋探索、船只建造与动物养殖。

**游玩：https://wuhuyixia.github.io/Ocean-Muck/**

## 快速开始

1. 点击游戏画面锁定鼠标，WASD 移动，Tab 释放鼠标。
2. 按 B 打开手工制造 2×2 合成栏，使用 4 木材合成制造台；选择快捷栏 7，向下瞄准空甲板，左键放置。
3. 靠近已放置的实体制造台按 E，打开 3×3 制造界面。B 始终打开手工制造，与实体制造台严格区分。点击背包材料后点击网格填写，也可点击配方书自动填入。点击制作消耗材料，设备进入库存。
4. 选择快捷栏对应设备，向下瞄准绿色建造预览并左键放置。放置只消耗已制作设备，不重复扣材料。
5. 按 V 驾驶/停船；在海水中按 C 潜水/上浮；E 采集或捕捉动物，G 喂养，F 进食，R 饮水，M 地图，Esc 暂停。

## 制造系统

手工制造（B，2×2）：制造台、船体地板、淡水补给、珍珠兑换，共4种专属配方。实体制造台（E，3×3）：收集网、动物围栏、净水器、捕鱼器、打捞钩升级、船帆升级、氧气瓶升级、斧头升级，共8种专属配方。两个制造界面使用互不重叠的配方书；手工制造无需制造台，高级制造需要靠近已放置的实体制造台3.1米内。制造消耗材料，放置只消耗已制作设备。

## 画面与世界

使用 Three.js、程序化海水着色器（多频波纹、菲涅耳反射近似、太阳高光）、程序化天空及云层、布帆、桅杆、缆绳、木板细节和第一人称手持工具。并非实时场景反射或完整海浪物理。14座不规则大型岛屿，基准半径17–46游戏单位，地图边界880×880游戏单位。船只平面位移，海底场景切换。动物围栏每格容纳2只鸡或山羊；喂养后每25秒产出食物。

## 存档和部署

每15秒 localStorage 自动存档，支持手动保存及JSON导入导出。v0.3地图和位置不变；旧存档新增设备库存默认为0。v0.2或更早存档因v0.3地图变更会重置位置和探索记录。GitHub Pages main/root 部署，Three.js 依赖 jsDelivr CDN。需要支持WebGL的浏览器；无云存档、真实船舶转向物理、独立营地或连续深度潜水。

## v0.5 新增

- 初始配备1级斧头，按8切换；登陆后靠近树木（约4米），准星对准树干，左键点击或在鼠标锁定时长按砍伐。树木初始3点耐久，1级斧头砍3次，倒下后获得5木材与1纤维，85秒再生。制造台可升级斧头（3金属、2木材），最高3级。E仍可采集矿物、植物纤维、捕捉动物或打开制造台。
- 鸡和山羊会在岛屿内随机游走、停顿、转向并摆动腿部；圈养动物在围栏范围内移动。未改变捕捉与产出机制。
- 增加几何水面起伏、海岸动态泡沫和实例化草丛。未实现完整海浪流体模拟或动物碰撞与繁殖。
- v0.4旧存档默认解锁1级斧头，其他数据保留。

## v0.6 背包与工坊

- I 打开独立背包：全部、材料、食物饮水、建筑设备、工具装备分类；显示实际持有数量、装备等级、物品用途。点击物品可直接食用、饮水或选择工具/建筑进行装备。当前为自动按种类堆叠的无限容量背包，暂不限制格数和重量，也不支持拖拽整理。
- B 固定打开2×2手工制造，E 靠近实体制造台开启3×3高级制造；两套配方严格分离。也可从背包进入手工制造或在附近有制造台时进入高级制造。
- 打开背包、制造菜单时暂停游戏模拟，Esc 关闭界面；关闭后点击场景重新锁定鼠标。
- v0.5存档继续使用，资源、建筑、船只、动物和装备等级保留；新增当前装备选择存档字段，旧存档默认装备打捞钩。

## v0.7 模块化建造与潜水

- Space 在岛屿和甲板跳跃；N 打开建造菜单，Q 旋转，X 拆除新增船体结构并返还物品。新增木墙、窗墙、门框、护栏、上层甲板和楼梯，支持基础边缘碰撞和楼梯高度检测。上层甲板与楼梯应放在相邻格，当前不支持任意多层或在二层继续建造。
- 手工新增木墙、窗墙、门框、护栏；制造台新增上层甲板和楼梯，总计18种配方。原背包和配方隔离保留。
- C 在水中进入潜水，Ctrl 下潜，Space 上升，C 返回水面，E 在约4–5米深度采集。当前水下场景可连续调整观察深度0.65–5.3米，但仍与水面场景切换，海床深度固定。
- 新增动态鱼群、气泡、海草和海底光斑，岛屿加入起伏山丘、岩石、花丛与部分石质遗迹装饰。
- HUD 精简、折叠菜单和深度指示器。旧存档新增建筑模块及库存默认为空，原资源和船只位置保留；玩家重新加载时回到当前位置基础地面高度。

## v0.7.1 快捷栏

- 独立物品格、原创 SVG 图标、数字快捷键、库存数量、工具等级及高亮选中状态。库存为零时图标变暗。
- N 建造槽入口；选择新增船体模块时显示对应名称、数量及旋转角度。
- H 打开/关闭操作指南，移除底部常驻长说明。原快捷键、存档与游戏玩法保持不变。

## v0.8.1 空间背包与画质设置

I 打开六列空间网格背包。物品占用1×1、1×2、2×1或2×2格，拖拽至空格整理，触屏可选择物品后点击移动物品及目标格。自动整理按钮重新排列物品。位置保存在存档内；旧存档自动排列，不改变物品数量。暂不限制堆叠数量，网格自动增加行数。右上角菜单提供低、中、高画质，调整渲染分辨率、阴影和岛屿显示距离，设置本地保存。修正昼夜时间对应关系及发现岛屿提示。
