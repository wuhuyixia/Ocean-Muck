# Ocean Muck · 深蓝漂流

v0.2 探险家：低多边形斜俯视角海洋探索与移动营地游戏。

**游玩：https://wuhuyixia.github.io/Ocean-Muck/**

## 核心循环

驾驶船只 → 海上打捞 → 登岛采集 → 潜水探索珊瑚、矿藏和沉船 → 扩建船只及营地 → 捕捉、喂养鸡与山羊 → 获得鸡蛋和羊奶 → 升级船帆及氧气瓶 → 探索更多岛屿。

- WASD / 方向键：移动或驾驶；V 在甲板上切换驾驶、停船；C 在水中潜水/上浮。
- E 采集附近资源、捕捉动物；G 在船上用纤维喂养；F 进食；R 饮水；B 制作升级；M 地图；Esc 暂停。
- 1 打捞钩、2 地板、3 收集网、4 动物围栏、5 净水器、6 捕鱼器、7 工作台。点击海面或甲板建造；绿色预览表示可建造。
- 每个围栏容纳两只动物；捕捉消耗2纤维，喂养后每25秒消耗每只动物1份饲料并产出鸡蛋或羊奶。
- 14座程序化岛屿，海底资源和沉船宝箱；氧气耗尽自动上浮并扣生命值。夜晚不再强制刷怪。

## 存档与部署

localStorage 每15秒自动存档，支持手动保存和JSON导入导出；兼容v0.1存档。保存船位置、营地、动物、饲料、探索记录、已采集海底物资和装备。重新加载返回水面、停船，漂浮物与采集冷却重置。没有云端同步。

GitHub Pages 使用 main / root 静态部署。首次加载依赖 jsDelivr Three.js CDN。当前营地与船只一体化，暂未实现独立多营地、船体转向物理、动物繁殖或连续深度潜水。
