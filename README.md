# Ocean Muck · 深蓝漂流

v0.3 航海时代：第一人称低多边形海洋探索与移动营地游戏。

**游玩：https://wuhuyixia.github.io/Ocean-Muck/**

## 操作

- 点击画面锁定鼠标，自由环顾；Tab 释放鼠标，Esc 暂停。移动端拖动环顾、轻触使用工具。鼠标锁定失败时可按住拖动环顾。
- WASD / 方向键：按视角方向移动或驾驶；Shift 加速步行/游泳；V 在甲板上切换驾驶、停船；C 在水中潜水/上浮。
- E 采集附近资源、捕捉动物；G 在船上用纤维喂养；F 进食；R 饮水；B 制作升级；M 地图。
- 1 打捞钩、2 地板、3 收集网、4 动物围栏、5 净水器、6 捕鱼器、7 工作台。准星向下瞄准建造；绿色预览表示可建造。
- 每个围栏容纳两只动物；捕捉消耗2纤维，喂养后每25秒消耗每只动物1份饲料并产出鸡蛋或羊奶。

## 世界

14座大型岛屿，基础半径约17–46游戏单位，随机种子决定轮廓、尺寸、朝向和地形。海岸具有不规则轮廓、浅滩与缓坡；岛内具有树林、矿石和植物。地图采用预设群岛布局加随机偏移，并非真实地理数据。船只采用平面位移，避免驶入陆地。海底仍采用独立场景切换。

## 存档与部署

localStorage 每15秒自动存档，支持手动保存和JSON导入导出；兼容旧版物资、建筑、动物与装备。因地图重构，旧存档首次加载时船只和玩家回到初始海域，岛屿探索与海底采集记录重置。重新加载时返回水面、停船，漂浮物与采集冷却重置。没有云端同步。

GitHub Pages 使用 main / root 静态部署，首次加载依赖 jsDelivr Three.js CDN。当前营地与船只一体化，暂未实现独立多营地、船体转向物理、动物繁殖或连续深度潜水。
